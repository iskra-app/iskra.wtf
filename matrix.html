Что такое Matrix

Matrix — открытый способ, которым приложения для переписки общаются между собой. Iskra — одно из таких приложений. Есть и другие, и все они друг друга понимают.

Здесь никто не главный

Matrix не принадлежит одной компании, которая может закрыть сервис, продать ваши данные или поменять правила. Серверов тысячи, и держат их фонды, сообщества и обычные люди. Можно поднять и свой.

Переписка остаётся вашей

Сообщения шифруются прямо на вашем устройстве, а расшифровать их может только собеседник. Сервер их хранит и пересылает, но прочитать не может.

Без номера телефона

Аккаунт не привязан ни к телефону, ни к почте: только имя пользователя и пароль.

С какого сервера начать

Аккаунт живёт на одном сервере, а писать можно людям с любого другого. На всех серверах ниже аккаунт можно создать прямо в Iskra.

  • matrix.org

    Самый большой сервер Matrix. Его держит фонд, который развивает сам Matrix. Великобритания Из России может быть недоступен

  • tchncs.de

    Один из старейших общественных серверов. Владелец держит и другие свободные сервисы. Германия

  • quassel.io

    Открытый сервер для повседневного общения, бесплатный для всех. Германия, сервер в Финляндии

  • nope.chat

    Сервер команды adminForge, которая держит и другие свободные сервисы. Есть мосты в другие мессенджеры. Германия

  • Свой сервер

    Можно поднять собственный сервер — тогда переписка будет полностью в ваших руках. Понадобятся свой домен и немного времени. Как это сделать
